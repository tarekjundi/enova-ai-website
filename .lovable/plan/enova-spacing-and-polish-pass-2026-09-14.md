# ENOVA spacing and polish pass

## Scope
Refine the existing site without changing its colors, content order, or page composition.

## Changes
- Increase the header height and logo size, with the logo shifted slightly left while preserving navigation placement.
- Remove the repetitive small brown eyebrow text above section headings and the decorative lines attached to that pattern.
- Improve vertical spacing and soften excessive borders so adjacent brown and cream sections feel deliberate rather than chopped up.
- Keep one unified closing call-to-action per page by removing the duplicate promotional block from the global footer; retain the footer navigation.
- Make every contact form field label clearly bold.
- Add subtle fade-and-rise reveals and refined interactive transitions across pages, with short mobile timings and reduced-motion support.

## Technical details
- Reuse the current `MotionElement` pattern, but make timing reliable, responsive, and cleanup-safe.
- Keep semantic color values unchanged and preserve existing form submission behavior, routes, copy, and responsive breakpoints.
- Verify the homepage, Solutions, Work, About, Contact, and Privacy pages at desktop and mobile sizes, including overflow and console checks.
